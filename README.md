# 문현준 · 조민아 모바일 청첩장

GitHub Pages로 바로 배포할 수 있는 정적 모바일 청첩장입니다. 별도 빌드나 패키지 설치가 필요 없습니다.

## 포함 기능
- 모바일 우선 반응형 디자인
- 예식 정보와 양가 부모님 표기
- 주소 복사
- 카카오맵 / 네이버 지도 / 티맵 바로가기
- 일정 저장용 `.ics` 파일
- 모바일 공유 기능 및 지원하지 않는 브라우저의 링크 복사 대체 동작
- 링크 미리보기용 Open Graph 메타 정보

## GitHub에 올리고 공개하기
1. GitHub에서 새 저장소(repository)를 만듭니다. 예: `wedding-invitation`
2. 압축을 풀고 **폴더 안의 파일과 폴더 전체**를 저장소 루트에 업로드합니다. `index.html`이 저장소 최상위에 있어야 합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 설정하고 **Save**를 누릅니다.
6. 잠시 후 `https://깃허브아이디.github.io/저장소이름/` 주소로 접속합니다.

## 수정할 곳
- 예식 정보/초대 문구/지도 링크: `index.html`
- 색상과 디자인: `css/style.css`
- 복사 및 공유 기능: `js/main.js`
- 일정 파일: `assets/wedding.ics`

## 배포 전 확인
- 현재 예식 정보는 제공해 주신 내용을 기준으로 입력했습니다.
- 실제 사진은 제공되지 않아 사진 없이 우아한 타이포그래피 중심으로 구성했습니다. 원하시면 `index.html`에 사진 섹션을 추가할 수 있습니다.
- 지도 앱 링크는 검색 링크입니다. 배포 전 각 앱에서 장소 검색 결과가 정확한지 확인해 주세요.
- 모바일 공유 API는 HTTPS 환경에서 가장 잘 작동하며, GitHub Pages는 HTTPS를 지원합니다.
- 카카오톡 링크 미리보기 이미지의 SVG 지원은 환경에 따라 다를 수 있습니다. 미리보기 이미지가 중요하면 `assets/og-image.svg`를 PNG로 교체하고 `index.html`의 `og:image` 경로도 바꿔 주세요.
